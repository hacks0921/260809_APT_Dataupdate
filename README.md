# 아파트 공시지가 연도별 변동 및 자산 분석 시스템 (2020~현재 API 수집)

본 프로젝트는 사용자가 입력한 아파트(도로명/지번 주소, 동, 호수)를 바탕으로 국토교통부 브이월드(V-World) API를 호출하여 **2020년부터 현재 연도까지의 실제 공시지가 데이터를 전수 자동 수집**하고 연도별 변동 추이 및 Total 합계를 시각화하는 시스템입니다.

## 📌 주요 기능
- **실시간 진행 로그 (Log Viewer)**: PNU 검색, 연도별(2020년~현재) API 호출 결과, 성공/실패 원인을 GUI 하단 로그 패널과 콘솔에 실시간 표출합니다.
- **2020년~현재 연도 전수 API 수집**: 2020년부터 현재 연도까지 순차적으로 API를 호출하여 실제 수집된 정제 데이터만 차트와 테이블에 표출합니다.
- **동적 아파트 등록 기능**: 다른 사용자가 본인의 집 [아파트 별칭, 주소, 동, 호수]를 입력하면 자동으로 PNU 탐색부터 2020년~현재 데이터 전수 수집까지 일괄 처리됩니다.
- **PyQt6 시각화 & 이중 차트**: 연도별 공시지가 테이블, 주택별 가격 추이선, Total 총 자산 막대/선 그래프를 제공합니다.

## 🚀 실행 방법

### 1. GUI 실행 (권장)
```bash
python main.py
```
- 상단 **"🏠 내 아파트 등록 & 2020년~현재 데이터 전수 API 자동 수집"** 폼에서 주소를 입력하고 버튼을 클릭합니다.
- 하단 실시간 로그 패널에서 2020년~현재 연도 데이터 수집 진행 상황을 확인하실 수 있습니다.

### 2. CLI 전수 자동 수집 실행
```bash
python main.py --cli
```

## 🔑 브이월드 API 인증키 참고사항
- 브이월드 API 호출 시 인증 에러(`INCORRECT_KEY`)가 발생하는 경우, [브이월드 마이포털](https://www.vworld.kr/)에서 발급받으신 인증키의 **등록 도메인/IP** 상태를 확인해 주세요.
- 코드의 `VWORLD_KEY` 및 `DEFAULT_DOMAIN` 상수를 수정하여 사용 환경에 맞춰 적용하실 수 있습니다.
