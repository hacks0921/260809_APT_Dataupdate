# 아파트 공시지가 연도별 변동 및 자산 분석 시스템
- 작성일: 2026-08-09
- 작성자: Antigravity Assistant (AI Pair Programmer)

## 프로젝트 개요
브이월드(V-World) OpenAPI 및 국토교통부 데이터를 연동하여 2020년부터 현재 연도(2026년)까지 보유 아파트 및 신규 아파트의 공동주택 공시가격 변동 추이와 총 자산(Total) 연도별 변동을 시각화(PyQt6 UI 현황표 및 Matplotlib 추이 그래프)하는 시스템입니다.

## 주요 기능
- **2020년~현재 전수 연도 공시가 연동**: 2020년부터 현재 연도까지의 공시가격 데이터를 수집/바인딩하여 연도별 추이 분석 제공.
- **원클릭 개별/일괄 데이터 조회**: 상단 집 카드 뷰에서 개별 주택 조회 및 전체 보유 집 일괄 조회 기능 제공.
- **신규 아파트 등록 및 그래프 자동 표출**: 사용자가 원하는 임의의 아파트(주소/동/호수)를 등록하면 2020년~2026년 공시가 변동 추이를 자동 수집/생성하여 그래프 및 테이블에 즉시 업데이트.
- **연도 누적 필터링**: 원하는 연도까지의 공시가격 및 자산 변동 선택 필터링 기능.
- **실시간 시스템 진행 로그 뷰어**: GUI 하단에 브이월드 API 통신 및 데이터 연동 진행 상황을 실시간 스트리밍.

- 도화현대홈타운2차 (인천광역시 미추홀구 숙골로 114 207동 405호)
- 진천 풍림아이원 (충청북도 진천군 풍림아이원 201동 1301호)
- 월피주공1단지 (경기도 안산시 상록구 광덕산안길 20 113동 801호)

## 시스템 요구사항 및 설치 패키지
- Python 3.11 이상
- PyQt6
- pandas
- matplotlib
- requests
- pytest

## 실행 방법

### 1. GUI 모드 실행 (기본)
```bash
python main.py
```

### 2. CLI 모드 실행
```bash
python main.py --cli
```

### 3. PNU 자동 검색
```bash
python main.py --find-pnu
```

### 4. 단위 테스트 실행
```bash
pytest tests/ -v
```

## 프로젝트 구조
- `main.py`: 메인 엔트리포인트 스크립트.
- `app_gui.py`: PyQt6 GUI 인터페이스 및 데이터 연동 비즈니스 로직.
- `my_properties_history.csv`: 2020년~2026년 공시가격 연도별 이력 데이터베이스.
- `tests/test_tracker.py`: 핵심 기능 단위 테스트 스크립트.
